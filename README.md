## 📌 Overview

This project implements a **Plagiarism Detection System** developed in **C**, designed to identify similarity between files by analyzing structural patterns rather than relying on naive text matching.

It supports multiple file formats and uses **tokenization** and **n-gram–based comparison** to produce meaningful similarity results.

---

## 🚀 Features

- 🔎 Similarity detection for **source code and text documents**
- 🧠 **N-gram–based comparison** for improved accuracy
- 📂 Supports multiple formats (TXT, PDF, DOCX)
- 📊 Clear and interpretable similarity reporting
- ⚙️ Efficient memory usage using pointers and dynamic allocation

---

## 🛠️ Technologies & Concepts Used

- **C Programming**
- File Handling
- Pointers
- Dynamic Memory Allocation
- String Processing
- Tokenization
- N-gram Similarity Analysis

---

## 🧩 How It Works (High Level)

1. Input files are read and preprocessed  
2. Text is tokenized into n-grams  
3. Structural similarity is computed  
4. A similarity score is generated and reported  

This approach focuses on **logic and structure**, making it more effective for code plagiarism detection.
